What happens between the prompt and the next word?

A language model passes your text through a stack of layers. Only the last one is meant to be read out, but the logit lens reads every layer the same way, and shows what the model would guess if it stopped there.

Pick a model, type a prompt or pick one, and press Run. The model runs in your browser; it is downloaded once and then kept.
